# ADR-0003: 기술 주제와 활동 유형을 분리한다

- 상태: 채택
- 결정일: 2026-07-15

## 맥락

기술 글은 내용의 주제와 작업이 일어난 맥락을 함께 가진다. 두 속성을 하나의 카테고리 목록에 섞으면
PostGIS 성능 글처럼 `데이터·성능`과 `개인 프로젝트`에 모두 해당하는 글을 일관되게 탐색하기 어렵다.

## 결정

글을 두 축으로 분류한다.

- 기술 주제: 백엔드·아키텍처, 인프라·운영, 데이터·성능, AI 시스템, 설계·개발 과정,
  트러블슈팅·신뢰성
- 활동 유형: 개인 프로젝트, 공모전·대회, 동아리·연합활동, 팀·학교 프로젝트, 학습·기타

글 하나는 기술 주제 하나와 선택적 활동 유형 하나를 가진다. 세부 기술은 태그로 표현하고 프로젝트
관계는 별도로 유지한다. 저장소의 작업 로그와 ADR은 구현 이력을 보존하고, 블로그 글은 하나의 기술
문제를 독립적으로 이해할 수 있도록 맥락과 검증을 설명한다.

## 대안

### 모든 분류를 단일 카테고리로 운영

기각했다. 기술 주제와 활동 맥락이 경쟁해 탐색 목적이 불명확해진다.

### 모든 저장소 기록을 블로그에 자동 복제

기각했다. 작은 변경이 기술 글을 압도하고 원문 commit·pull request와 떨어져 사실 검증이 어려워진다.

### 저장소 기록만 유지

기각했다. 원본에는 가장 가깝지만 여러 파일에 걸친 하나의 기술 문제를 순서대로 읽기 어렵다.

## 결과와 재검토

카테고리 관리 화면과 글 목록은 두 그룹을 분리해 보여준다. 글이 많아져 두 축만으로 탐색하기 어려워지면
검색과 복수 기술 주제 분류를 검토한다.
